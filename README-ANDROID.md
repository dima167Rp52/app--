# FileMaster для Android

Android-версия FileMaster. Приложение позволяет выбрать папку на устройстве, переходить по вложенным папкам и просматривать текстовые файлы и исходный код.

## Получение APK

1. Открой вкладку **Actions** репозитория.
2. Выбери запуск **Build FileMaster Android APK**.
3. Дождись успешного завершения.
4. Внизу страницы скачай артефакт **FileMaster-Android-APK**.
5. Распакуй ZIP и установи `app-debug.apk` на Android.

При первом запуске выбери папку, к которой приложение получит доступ. Разрешение сохраняется для следующих запусков.

Предпросмотр файлов размером более 2 МБ и бинарных файлов отключён.
